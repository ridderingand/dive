# Dive Studio

From an approved Dive Club cut to the file you ship, with no timeline to edit. See clips and their files per person, try concepts built from templates, review on Inflight, and prompt the changes.

```bash
bun install
bun run dive setup
bun run dev            # http://localhost:4410
```

Everything an agent needs is in [AGENTS.md](AGENTS.md). Commands are in `bun run dive help`.
