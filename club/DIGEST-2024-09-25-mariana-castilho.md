## Takeaways (Granola)

- Dev-tool design = translating complex tasks into simple flows; preview builds provide richer feedback than static Figma files
- Learn code by building real projects and learning the next needed step, not tutorials-to-mastery
- For straightforward interfaces, skip Figma for code; for visually unclear work (empty states), use Figma to explore
- Design systems focus on atomic primitives; complex components stay uncomponentized because they change
