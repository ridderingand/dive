## Summary

Returning guest James McDonald (first on Dive Club 2023-11-09, "Staying ahead of web design trends"), introduced by Ridd as "easily one of my favorite visual designers on the planet," screen-shares how he now designs *and builds* web work with Claude. Arc: the new AccessGrid homepage (a client making mobile-wallet credentials for buildings and apartments) built in Claude with all its animations → finding a visual motif (the grid-and-connector pattern, the L shapes from the logo) and building throwaway mini tools with parameters and a random button to explore it → how that changes creativity for a designer with no engineering background ("apprehension" about tools like Claude and Codex; the core idea used to take longest in Figma) → when he reaches for Figma vs Claude (a "mind switch" where designing in Claude was quicker; Figma still for high-fidelity direction, never wireframes; Claude for the details, interaction and motion) → reusing a shelved cube animation (Ridd: Soleio's "great designers self-plagiarize"; his own "Ethereal Connector" on an old Inflight website) → animation without storyboards (hand Claude one artboard via the MCP) and the creepy Face ID dot-matrix face tool (halftone won; the white scan added after) → Onlook, his own Mac app for Ring doorbell cameras (Cosmos and Midjourney explorations, Claude as the guide and edge-case spotter, the website walkthrough as his first back-and-forth with Claude) → positioning as a freelancer and his first contract as a builder (AccessGrid; codebase set up "just last week").

Core claims: custom tools beat static mockups for discovering a visual language — build parameters plus a random button and outputs you'd never draw "could quite easily" end up in a brand guideline book; Figma is still faster for high-level directions and layout, but there is now an overlap where Claude "gives you like a, freedom to explore something that you might not be able to fully do in Figma" plus a sense of how it actually works; animation work moves from storyboarding for engineers to handing Claude an artboard and massaging "a living, breathing idea"; shelved ideas become reusable once building is cheap (self-plagiarism); Claude is a strong guide for a first-time app builder (to-do lists, security questions, edge cases); being able to design and build is "another skill set" for a freelancer — "a company can hire, you to do it all" — and the enjoyment is what makes it stick. Why it matters: a top visual designer with a pure Photoshop → Sketch → Figma background describing, concretely, the shift into building his own work.
