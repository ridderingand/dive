## Takeaways (Granola)

- AI is a direction problem, not a prompting problem — visual references and moodboards are the real advantage.
- Workflow: moodboard → generate → iterate → refine, one change at a time.
- Consistency is the recurring proof point — reference-heavy workflows, style libraries, Magic Path master-prompt system.
- Midjourney for aesthetic direction; Nano Banana Pro for realism, text accuracy, and surgical edits.
- "AI smooth slop" critique — too-perfect editorial outputs need refinement.
- Current "AI designer" positioning window ~6–12 months; clients want better/cheaper/faster.
- Daily taste practice — 15,000+ saved references and cultural consumption as creative direction.
