## Takeaways (Granola)

### Prototyping / tight feedback loops
- Closer to the real thing = more accurate feedback loop
- Same brain understanding tradeoffs tightens iteration (less cross-discipline transfer)
- Valuable for startups because he tightens loops

### Code vs abstract
- Trend: people who can code sketch then jump to "sticks and stones" code prototypes
- AI lowers barrier to entry for coding; ceiling still high
- Building with real materials highlights edge cases; static mockups aren't a forcing function

### Design engineering critique
- Most "design engineer" postings = marketing page implementer / DS / polish — missed opportunity
- Engineering is a mindset / problem-solving approach
- Tiny design decisions at edge cases make Linear-level quality
- Designer who can code leads with complex design challenges
