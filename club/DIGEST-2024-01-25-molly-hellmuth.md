## Takeaways (Granola)

Granola-weak: Notion episode Scratchpad while editing (no Granola Editing note). Normalized from that scratchpad — do not invent a Granola note:

### Regret horizon / slow adoption
- Quote to keep: "what's going to be the thing we regret in six months from now?"
- Super / base components as prior trends that had to be undone once Figma shipped bulk selection / better component features
- Variables still "taking form" — experiment quickly, adopt slowly; start with easy wins (number variables)
- Prefer nimble foundation over 100% coverage; semantic variables more attainable than a full primitives matrix

### Power → usability
- Shift from making components as powerful as possible to as usable as possible
- Smaller component sets for discoverability (search "outline button" vs buried property dropdowns)
- Split `type` (primary/secondary/danger); only keep height/size in the set when height is the only change

### Styles + variables
- Feeding variables into styles as an adoption / walk-back pattern
- Plugin link candidates: Variables Pro, Super Palette, Contrast, 8shapes
