## Summary

Geoffrey Litt (Ink & Switch → Notion) frames a decade-long obsession with **malleable software** — tools users reshape in local context rather than SaaS dictating every choice. Arc: ed-tech Excel-export wake-up → MIT + Ink & Switch (Embark document-centric travel) → Notion as platform shift during AI volatility → Nightmare Bicycle (expose structure, don’t hide it behind mode buttons) → AI chat as power-user “raw gears” UI → canvas/Spellburst branching → **human–AI collaboration = version-control problem** (Patchwork research; live-edit custom tools need branches too) → malleable ≠ disposable (apartment furniture metaphor; shared stable environments) → designer as pattern-language steward (Christopher Alexander) → **coding like a surgeon** (stay in the work; AI preps/assists) → advice: use AI to learn details, not cheat homework. Core claims: platform-level malleability not single-app; document-centric over “build an app” blank boxes; true simplicity exposes structure; version control as creative primitive for AI collab. Why it matters: design philosophy for AI-era tools that stay editable and shareable like documents — not Inflight Figma→preview workflow gold.
