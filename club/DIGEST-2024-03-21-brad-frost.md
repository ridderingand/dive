## Summary

Brad Frost (**Big Medium**) on design systems as **front-end infrastructure** plus human service work — then his call for a **global design system**, AI that frees DS teams from rebuilding badges, and how designers should talk to engineers. Arc: Big Medium teaches orgs to fish (stand up / evolve / merge / retire systems; culture > deliver-and-ride-off) → successful DS teams are **service-oriented**, not ivory tower (embed in product reviews; ask “how can we help?”) → **pace layers**: product moves fast, DS moves slower/sturdier; don’t force either pace; fill gaps with third-party/scrappy until ready; seed via **pilot projects** (e.g. checkout redesign) → startups: even a one-person jewelry site benefits from component reuse; complexity only when you feel the pinch (**Gall’s Law**); don’t rival Material.io on day one → **global design system**: every org rebuilds buttons/badges/date pickers; propose WCAG/ARIA/W3C-blessed, style-less prefab layer between HTML and org DS → AI: train on conventions → scaffold component code (~80%); generate 700 login variants for human curate; just-in-time personalized docs (“Clippy on steroids”) → Monday morning in an AI world: less rectangle creation, more outbound curation/analytics/strategy → designer↔eng: humility, shared prop/token language, short validate-before-handoff chats → closer: Aug 17 Pittsburgh benefit concert. Core claims: DS value is connective tissue between people; commoditize the rote so humans do service + judgment; shared web primitives should stop being rebuilt.
