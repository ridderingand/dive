## Summary

Katarina Batina (Shop design leadership at Shopify) sits with Ridd on **Making big bets with design** — how Shop takes audacious product bets (window-shopping Superfeed, Shop Store, undercart) while building a designers-in-code paradise. Arc: Shop origin (Arrive + Shopify Pay → shopping-as-entertainment Superfeed) → density vs portal-into-a-brand-story, gentle AI video + merchant posts → Shop Store tension (cohesive buyer UX vs merchant expression) and **Luke Dupont**'s Claude Code / production-data storefront prototypes hosted on Quick → metrics vs vision: reset baseline because you rarely beat the incumbent on first try (Jess Erickson signup story) → John Rendle undercart from annual "shoplifting" pencils-down sprints; craft earned via trusted cross-functional relationships and Tobi's "open Shop and see something delightful" → inspiration from physical retail (Skims, Tecovas, Outdoor Voices) → design-led push from Origami/React Native toward Swift/Kotlin because agents and designers write native more easily → don't get stuck shipping-to-prod; render the full idea (Artifact as multi-artifact workspace) → editing/discipline so the app doesn't overcook; roadmap in microdoses instead of annual moonshots → excitement = compelling prototype + story, unlocked further by **access to data** (data portal via agents) → Vault / GSD for legible decisions with MCP → leadership stays craft-close; one-on-ones open prototypes → material language is words: edit and give feedback to agents with precise critique → capitalize by jumping craft ponds and Toby's "figure out what's true and then figure out what to do about it."

Core claims: Shop wins by taking bets that thwart "best practice" density and by resetting risk baselines so iteration can catch up; the AI-era leverage for designers is production-data prototyping + data legibility + high-fidelity language for agent critique — not shipping every idea to production; strategy now arrives week-to-week from prototypes that catch heat, not January vision decks.

Why it matters: concrete Shop process for big-bet design (shoplifting, Quick/Artifact sharing, baseline resets) plus a leadership frame for the agentic era where editing and data access matter as much as vibe-coding.
