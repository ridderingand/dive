## Summary

Vitaly Friedman (Smashing Magazine) surveys AI UX beyond the empty chat box — patterns that gather context *before* generation and build trust without “AI” badges. Arc: people shouldn’t have to learn prompt engineering; design affordances should structure intent → concrete patterns (templates, filters that augment prompts, assisted authoring, framework fields: main prompt / context / output) → **slow people down before they submit** so prompts are succinct/accurate (sustainability + wasted 20–30s walls of text) → dynamic interfaces / old-school affordances / loading-state creativity → trust via sources, scoping, and reflecting “I know you” without dumping memory as prose (vegan/carrot badges) → refinement journey as first-class → quiet AI (Dovetail-style under the hood) vs loud AI-first → NN/g: labeling features “AI” can hurt trust → future: fewer prompt guides, more guided success before free-tier limits. Core claims: slow down prompting; don’t badge AI; reflect memory non-textually; quiet > loud.
