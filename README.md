# dive

Ridd's knowledge vault for Dive Club, Dive Radio, and later Decimals / talent.

This is the source of truth for what was said and what we might make from it. Open it in Obsidian. GitHub is the cloud copy.

- **This vault** — transcripts, digests, clips, pitches. Agent-readable. One writer: Dive Club Ideas.
- **Notion** — episode production only (writeups, status, covers, emails). Not an idea archive.
- **Reflect** — personal journal. Stay out.

## Layout

```
club/            Dive Club episodes (raw + DIGEST-)
radio/           Dive Radio
decimals/        later
clips/           clip-sized ideas, one note per clip
pitches/inbox.md Friday / standing pitches
writers-room/    session notes
taxonomy.md      controlled tags
AGENTS.md        rules for the writer
```

## One writer

Dive Club Ideas commits here. Other agents hand over durable bits; they do not keep parallel folders. Humans browse in Obsidian. Do not also keep a live clips inbox in Notion.
